Credenciales

Gestionar credenciales de la API de Hacienda para envío de documentos.

GET /api/v1/credentials

Estado de Credenciales

Verifica si las credenciales de Hacienda están configuradas para el tenant actual. No retorna las credenciales en sí, solo su estado de configuración.

Cuerpo de la Solicitud

Este endpoint no requiere cuerpo de solicitud.

Response — 200 OK

{
  "configured": true,
  "username": "hacienda_user@example.com",
  "client_id": "abc123def456",
  "last_validated_at": "2025-07-10T08:22:00Z"
}

Response — 200 OK (sin configurar)

{
  "configured": false,
  "username": null,
  "client_id": null,
  "last_validated_at": null
}
POST /api/v1/credentials

Configurar Credenciales

Establece las credenciales de la API de Hacienda. Las credenciales se validan contra el proveedor de identidad (IDP) de Hacienda antes de guardarse. Si la validación falla, las credenciales no se almacenan.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
username string Sí Usuario registrado ante Hacienda
password string Sí Contraseña o contraseña de llave privada del usuario en Hacienda
client_id string Sí Identificador del cliente OIDC registrado en Hacienda
client_secret string Sí Secreto del cliente OIDC para autenticación OAuth2

Response — 200 OK

{
  "configured": true,
  "username": "hacienda_user@example.com",
  "client_id": "abc123def456",
  "last_validated_at": "2025-07-13T11:00:00Z"
}

Response — 422 Unprocessable Entity

{
  "error": "credentials_validation_failed",
  "message": "Las credenciales no pudieron validarse contra el IDP de Hacienda",
  "details": {
    "field": "client_secret",
    "reason": "El client_secret proporcionado es inválido"
  }
}
PUT /api/v1/credentials

Actualizar Credenciales

Actualiza las credenciales de Hacienda existentes. Solo los campos incluidos en la solicitud serán modificados. Las credenciales actualizadas se validan contra el IDP de Hacienda antes de guardarse.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
username string No Nuevo usuario registrado ante Hacienda
password string No Nueva contraseña o contraseña de llave privada
client_id string No Nuevo identificador del cliente OIDC
client_secret string No Nuevo secreto del cliente OIDC

Response — 200 OK

{
  "configured": true,
  "username": "nuevo_usuario@example.com",
  "client_id": "xyz789ghi012",
  "last_validated_at": "2025-07-13T11:30:00Z"
}

Response — 422 Unprocessable Entity

{
  "error": "credentials_validation_failed",
  "message": "Las credenciales actualizadas no pudieron validarse contra el IDP de Hacienda",
  "details": {
    "field": "username",
    "reason": "El usuario no está registrado ante Hacienda"
  }
}
