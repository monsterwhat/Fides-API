Puntos de Venta

Gestionar puntos de venta (terminales) bajo sucursales.

GET /api/v1/branches/{branch_id}/points-of-sale

Listar puntos de venta de una sucursal

Recupera todos los puntos de venta (terminales) registrados para una sucursal específica.

Parámetros de Ruta

Campo Tipo Requerido Descripción
branch_id uuid Sí Identificador único de la sucursal.

Cuerpo de la Respuesta

Devuelve una lista de puntos de venta asociados a la sucursal.

Response — 200 OK

[
  {
    "id": "d4e5f6a7-b8c9-0123-def4-567890abcdef",
    "branch_id": "c3d4e5f6-a7b8-9012-cdef-345678901234",
    "code": "CAJA-01",
    "name": "Caja Principal",
    "active": true
  },
  {
    "id": "e5f6a7b8-c9d0-1234-ef56-7890abcdef01",
    "branch_id": "c3d4e5f6-a7b8-9012-cdef-345678901234",
    "code": "CAJA-02",
    "name": "Caja Secundaria",
    "active": false
  }
]
POST /api/v1/branches/{branch_id}/points-of-sale

Crear punto de venta

Registra un nuevo punto de venta (terminal) dentro de una sucursal. El campo code debe ser único dentro de la sucursal.

Parámetros de Ruta

Campo Tipo Requerido Descripción
branch_id uuid Sí Identificador único de la sucursal.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
code string Sí Código de terminal único dentro de la sucursal (ej. "CAJA-01", "TERMINAL-03").
name string Sí Nombre descriptivo del punto de venta.
active boolean No Estado del punto de venta. Por defecto true. Los terminales inactivos no pueden emitir documentos.

Request — Ejemplo

{
  "code": "CAJA-01",
  "name": "Caja Principal",
  "active": true
}

Response — 201 Created

{
  "id": "d4e5f6a7-b8c9-0123-def4-567890abcdef",
  "branch_id": "c3d4e5f6-a7b8-9012-cdef-345678901234",
  "code": "CAJA-01",
  "name": "Caja Principal",
  "active": true
}

Response — 409 Conflict

{
  "error": "pos_code_already_exists",
  "message": "Ya existe un punto de venta con el código proporcionado para esta sucursal."
}
GET /api/v1/points-of-sale/{id}

Obtener punto de venta por ID

Recupera un punto de venta específico por su identificador único.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único del punto de venta.

Cuerpo de la Respuesta

Devuelve el objeto de punto de venta.

Response — 200 OK

{
  "id": "d4e5f6a7-b8c9-0123-def4-567890abcdef",
  "branch_id": "c3d4e5f6-a7b8-9012-cdef-345678901234",
  "code": "CAJA-01",
  "name": "Caja Principal",
  "active": true
}

Response — 404 Not Found

{
  "error": "point_of_sale_not_found",
  "message": "No se encontró un punto de venta con el ID proporcionado."
}
GET /api/v1/points-of-sale/by-code/{branch_id}/{code}

Obtener punto de venta por código

Recupera un punto de venta utilizando el ID de la sucursal y el código de terminal. Útil cuando se conoce el código pero no el UUID.

Parámetros de Ruta

Campo Tipo Requerido Descripción
branch_id uuid Sí Identificador único de la sucursal.
code string Sí Código de terminal del punto de venta (único dentro de la sucursal).

Cuerpo de la Respuesta

Devuelve el objeto de punto de venta.

Response — 200 OK

{
  "id": "d4e5f6a7-b8c9-0123-def4-567890abcdef",
  "branch_id": "c3d4e5f6-a7b8-9012-cdef-345678901234",
  "code": "CAJA-01",
  "name": "Caja Principal",
  "active": true
}

Response — 404 Not Found

{
  "error": "point_of_sale_not_found",
  "message": "No se encontró un punto de venta con el código proporcionado para la sucursal indicada."
}
PUT /api/v1/points-of-sale/{id}

Actualizar punto de venta (parcial)

Actualiza parcialmente los campos de un punto de venta. Solo los campos incluidos en el cuerpo serán modificados.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único del punto de venta.

Cuerpo de la Solicitud

Todos los campos son opcionales. Incluya solo los campos que desea modificar.

Campo Tipo Requerido Descripción
code string No Código de terminal único dentro de la sucursal.
name string No Nombre del punto de venta.
active boolean No Estado activo/inactivo del punto de venta.

Request — Ejemplo

{
  "name": "Caja Principal - Remodelada",
  "active": true
}

Response — 200 OK

{
  "id": "d4e5f6a7-b8c9-0123-def4-567890abcdef",
  "branch_id": "c3d4e5f6-a7b8-9012-cdef-345678901234",
  "code": "CAJA-01",
  "name": "Caja Principal - Remodelada",
  "active": true
}

Response — 404 Not Found

{
  "error": "point_of_sale_not_found",
  "message": "No se encontró un punto de venta con el ID proporcionado."
}
