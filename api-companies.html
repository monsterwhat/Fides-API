GET /api/v1/companies

Obtener perfil de empresa del tenant

Recupera el perfil de empresa asociado al tenant autenticado. Cada tenant tiene como máximo un perfil de empresa registrado.

Parámetros de Ruta

No aplica. El tenant se infiere del token de autenticación.

Cuerpo de la Respuesta

Devuelve el perfil de empresa del tenant.

POST /api/v1/companies

Crear perfil de empresa

Crea el perfil de empresa para el tenant actual. Solo se permite un perfil de empresa por tenant. Si ya existe uno, se retornará un error 409 Conflict.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
trade_name string Sí Nombre comercial de la empresa.
legal_name string Sí Razón social completa (nombre legal registrado).
id_type string Sí Tipo de identificación: "01" (Cédula física), "02" (Cédula jurídica), "03" (DIMEX).
id_number string Sí Número de identificación tributaria.
activity_code string No Código de actividad económica según CABYS (Clasificación de Actividades Económicas por Secciones).
phone string No Número telefónico de la empresa. Formato internacional recomendado.
email string No Correo electrónico de contacto.
address object No Objeto con la dirección física de la empresa.
address.province string No Provincia.
address.canton string No Cantón.
address.district string No Distrito.
address.neighborhood string No Barrio o conjunto residencial.
address.street string No Dirección exacta: calle, avenida, número.
address.details string No Información adicional de la dirección (piso, oficina, referencias).
address.postal_code string No Código postal.

PUT /api/v1/companies/{id}

Actualizar empresa (parcial)

Actualiza parcialmente los campos de un perfil de empresa. Solo los campos incluidos en el cuerpo de la solicitud serán modificados. Los campos omitidos mantienen su valor actual.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único de la empresa.

Cuerpo de la Solicitud

Todos los campos son opcionales. Incluya solo los campos que desea modificar.

Campo Tipo Requerido Descripción
trade_name string No Nombre comercial de la empresa.
legal_name string No Razón social completa.
id_type string No Tipo de identificación: "01", "02", o "03".
id_number string No Número de identificación tributaria.
activity_code string No Código CABYS de actividad económica.
phone string No Número telefónico.
email string No Correo electrónico de contacto.
address object No Objeto de dirección completo que reemplaza el valor actual.

Request — Ejemplo

{
  "phone": "+506 2222-4444",
  "email": "nuevo-contacto@comervalley.co.cr"
}
