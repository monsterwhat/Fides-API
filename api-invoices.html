GET /api/v1/invoices

Listar facturas (paginado)

Devuelve una lista paginada de todas las facturas del tenant autenticado.

Parámetros de Consulta

Campo Tipo Requerido Descripción
page integer No Número de página. Por defecto: 1.
page_size integer No Cantidad de elementos por página. Máximo: 100. Por defecto: 20.
status string No Filtrar por estado de la factura. Valores válidos: draft, signed, submitted, accepted, rejected.

POST /api/v1/invoices

Crear una nueva factura

Crea una nueva factura electrónica. El servidor genera el XML, calcula el SHA-256 y almacena el documento en estado draft.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
doc_type string Sí Tipo de documento. Use "01" para factura electrónica.
key string Sí Clave numérica de 50 dígitos que identifica el documento ante Hacienda.
sequential string Sí Número consecutivo de 10 dígitos. Debe ser único por tipo de documento y sucursal.
date string (ISO 8601) Sí Fecha y hora de emisión del documento con offset de zona horaria.
seller_name string Sí Nombre o razón social del emisor.
seller_id_number string Sí Número de identificación del emisor (cédula jurídica, física, etc.).
seller_id_type string Sí Tipo de identificación del emisor: "01" = cédula física, "02" = cédula jurídica, "03" = dimex, "04" = pasaporte.
receiver_name string Sí Nombre o razón social del receptor.
receiver_id_number string Sí Número de identificación del receptor.
receiver_id_type string Sí Tipo de identificación del receptor. Mismos valores que seller_id_type.
receiver_email string Sí Correo electrónico del receptor. Hacienda envía la factura a esta dirección.
activity_code string Sí Código de actividad económica según el catálogo CNAE de Hacienda.
details array Sí Lista de líneas de detalle. Cada elemento incluye: quantity (number), unit_code (string), unit_price (number), description (string), subtotal (number), tax_rate (number, porcentaje), tax_amount (number).
