Reportes

Consultas analíticas de ventas, impuestos y documentos. Todos los endpoints aceptan parámetros de fecha para filtrar por período.

GET /api/v1/reports/summary

Resumen de ventas

Get an aggregated sales summary for the specified period including total sales, document count, average ticket, and tax totals.

Parámetros de Consulta

CampoTipoRequeridoDescripción
start_datestringSíStart of the reporting period (ISO 8601)
end_datestringSíEnd of the reporting period (ISO 8601)

Response — OK (200)

{
  "total_sales": 4850000.00,
  "document_count": 342,
  "average_ticket": 14180.12,
  "total_tax": 630500.00,
  "total_discount": 125000.00
}
GET /api/v1/reports/sales-by-period

Ventas por período

Break down sales by time period (day, week, or month). Useful for trend analysis.

Parámetros de Consulta

CampoTipoRequeridoDescripción
start_datestringSíStart of the reporting period (ISO 8601)
end_datestringSíEnd of the reporting period (ISO 8601)
periodstringNoGranularity: "day", "week", or "month". Default: "day"

Response — OK (200)

[
  {
    "period": "2026-01-01",
    "total_sales": 185000.00,
    "document_count": 12
  },
  {
    "period": "2026-01-02",
    "total_sales": 210500.00,
    "document_count": 15
  },
  {
    "period": "2026-01-03",
    "total_sales": 165750.00,
    "document_count": 9
  }
]
