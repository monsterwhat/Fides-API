Devuelve una lista de sucursales asociadas a la empresa.

POST /api/v1/companies/{company_id}/branches

Crear sucursal

Registra una nueva sucursal dentro de una empresa. El campo code debe ser único dentro de la empresa.

Parámetros de Ruta

Campo Tipo Requerido Descripción
company_id uuid Sí Identificador único de la empresa.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
code string Sí Código único de la sucursal dentro de la empresa (ej. "MATRIZ", "SUC-001").
name string Sí Nombre descriptivo de la sucursal.
phone string No Número telefónico de la sucursal.
email string No Correo electrónico de contacto.
address object No Objeto con la dirección física de la sucursal.
address.province string No Provincia.
address.canton string No Cantón.
address.district string No Distrito.
address.neighborhood string No Barrio o conjunto residencial.
address.street string No Dirección exacta.
address.details string No Información adicional de la dirección.
address.postal_code string No Código postal.

Request — Ejemplo

{
  "code": "SUC-ALAJUELA",
  "name": "Sucursal Alajuela",
  "phone": "+506 2444-5555",
  "email": "alajuela@comervalley.co.cr",
  "address": {
    "province": "Alajuela",
    "canton": "Alajuela",
    "district": "Guadalupe",
    "neighborhood": "",
    "street": "Avenida Central, 100 metros sur",
    "details": "Edificio Plaza Comercial, local 5",
    "postal_code": "20101"
  }
}

PUT /api/v1/branches/{id}

Actualizar sucursal (parcial)

Actualiza parcialmente los campos de una sucursal. Solo los campos incluidos en el cuerpo serán modificados.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único de la sucursal.

Cuerpo de la Solicitud

Todos los campos son opcionales. Incluya solo los campos que desea modificar.

Campo Tipo Requerido Descripción
code string No Código único de la sucursal.
name string No Nombre de la sucursal.
phone string No Número telefónico.
email string No Correo electrónico.
address object No Objeto de dirección completo que reemplaza el valor actual.

Request — Ejemplo

{
  "name": "Sucursal Alajuela Centro",
  "phone": "+506 2444-6666"
}

Response — 200 OK

{

  "phone": "+506 2444-6666",
