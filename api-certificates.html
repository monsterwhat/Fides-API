POST /api/v1/certificates

Subir Certificado

Sube un nuevo certificado digital en formato P12/PFX. El archivo debe contener la llave privada y el certificado de cadena completa.

Cuerpo de la Solicitud

Content-Type: multipart/form-data

Campo Tipo Requerido Descripción
file binary Sí Archivo P12/PFX del certificado digital
password string Sí Contraseña del archivo P12/PFX
alias string No Nombre descriptivo para el certificado. Si se omite, se genera a partir del subject name.

DELETE /api/v1/certificates/{id}

Desactivar Certificado

Desactiva un certificado digital (eliminación lógica). El certificado no se elimina del sistema, sino que se marca como inactivo y ya no puede usarse para firmar documentos.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único del certificado a desactivar

Response — 200 OK

{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "active": false,
  "message": "Certificado desactivado correctamente"
}
