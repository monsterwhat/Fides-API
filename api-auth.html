Autenticación

Endpoints protegidos para gestionar la autenticación del usuario, incluyendo cambio de contraseñas y revocación de tokens.

PUT /api/v1/auth/password

Cambiar contraseña

Change the authenticated user's password. Requires current password verification.

Request Body

Campo Tipo Requerido Descripción
current_password string Sí Current password for verification
new_password string Sí New password (minimum 8 characters)

Response — 200 OK

{
  "success": true,
  "data": {
    "message": "Password changed successfully"
  }
}
POST /api/v1/auth/revoke

Revocar token

Revoke a JWT access or refresh token, adding it to the blacklist. The token will no longer be valid for authentication.

Request Body

Campo Tipo Requerido Descripción
token string Sí The JWT token to revoke

Response — 200 OK

{
  "success": true,
  "data": {
    "message": "Token revoked successfully"
  }
}

A revoked token cannot be restored. Client must obtain a new token via /auth/token.
