GET /api/v1/submissions

Listar envíos

Devuelve una lista paginada de todos los envíos de documentos a Hacienda.

Parámetros de Consulta

Campo Tipo Requerido Descripción
page integer No Número de página. Por defecto: 1.
page_size integer No Cantidad de elementos por página. Máximo: 100. Por defecto: 20.
status string No Filtrar por estado del envío. Valores válidos: pending, processing, accepted, rejected, error.

POST /api/v1/submissions

Enviar un documento a Hacienda

Envía un documento firmado previamente al Ministerio de Hacienda de Costa Rica para su validación y aceptación. El documento debe tener estado signed.

Cuerpo de la Solicitud

Campo Tipo Requerido Descripción
document_id uuid Sí Identificador único del documento firmado que se desea enviar a Hacienda.

GET /api/v1/submissions/{id}

Obtener estado del envío

Recupera el estado actual de un envío a Hacienda, incluyendo la clave recibida y la respuesta del servicio.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único del envío.

Tabla de Estados

Estado Descripción
Pending El envío está en cola, esperando ser procesado.
Processing El envío se está transmitiendo a Hacienda.
Accepted Hacienda aceptó el documento. La clave electrónica se encuentra disponible.
Rejected Hacienda rechazó el documento. Consulte el mensaje de respuesta para más detalles.
Error Ocurrió un error al comunicarse con Hacienda. Puede reintentar el envío.

POST /api/v1/submissions/{id}/retry

Reintentar un envío fallido

Reenvía a la cola de procesamiento un envío que terminó en estado Rejected o Error. Solo se permiten reintentos para envíos en estos estados.

Parámetros de Ruta

Campo Tipo Requerido Descripción
id uuid Sí Identificador único del envío a reintentar.
