Descripción General

Fides es una API de facturación electrónica sin estado para Hacienda de Costa Rica. Todos los endpoints tienen el prefijo /api/v1.

Formato de Respuesta

Todas las respuestas siguen un sobre JSON estándar:

{
  "success": true,
  "data": { ... },
  "error": null
}

Paginación

Los endpoints de lista devuelven resultados paginados con campos total, page y page_size.

Autenticación

Fides soporta dos métodos de autenticación:

Llave API

Incluya la llave API en el header Authorization como token Bearer.

Authorization: Bearer fides_xxxxxxxxxxxxxxxx

Token JWT

Obtenga un JWT mediante el endpoint /auth/token e inclúyalo en el header Authorization.

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

Errores

Todos los errores devuelven una respuesta JSON estructurada:

{
  "success": false,
  "data": null,
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Invalid input",
    "timestamp": "2025-01-01T00:00:00Z",
    "correlation_id": "uuid",
    "details": []
  }
}
